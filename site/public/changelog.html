June 6, 2026 — Belmont Day
Major Strategy Overhaul

New Hard Rules:

  • Rule No short fields — skip any race with 5 or fewer horses
  • Rule No maiden races — never bet MCL or MSW, form too unreliable
  • Rule Sit out inside lone speed fave — pass when fave is post 1-3, E style, only speed in race (exception: pace duel present)
  • Rule Exclude fave from exacta on sharp class drop — vulnerable favorite signal

New Skill Filters (BOLOs):

  • BOLO Layoff + no workouts — hard skip on 90+ day layoff with no works (exception: sharp workout pattern = fresh angle)
  • BOLO Sharp class drop — yellow flag; context determines play vs. avoid
  • BOLO Recent life — prefer horses with visible recent form; full checklist for identification
  • BOLO Troubled-trip angle — horses with genuine trouble last out are underbet next time; strongest when today's setup is cleaner

New Offensive Strategy:

  • Strategy Beat the vulnerable favorite — identify fave weakness (style + post + pace) and back the horse whose style profits from the same scenario
  • Strategy Pace makes the race — map E horses first; pace duel vs. lone speed determines the whole race read
  • Strategy Exacta exclusion triggers — leave fave out of exacta on traffic (inside non-E) or pace (speed in duel / closer with no pace) triggers

Staking:

  • Strategy Double stake on vulnerable fave in long field — 10+ horses + confirmed vulnerability = $100 win instead of $50

Infrastructure:

  • Running-style personas (E / E/P / P / S) — tagged on every horse in field table
  • Field-size glossary (short = 5 or fewer, long = 10+)
  • Full execution sequence rewritten — 5 phases, 24 steps, every rule is a gate
  • DRF data extraction methods added to every step — each rule knows exactly which fields to read

Removed:

  • Removed S8 — Track bias alignment — requires live race-day observation, not executable from face book data
May 30, 2026
Foundation Established

Core Strategy (v1):

  • Rule Never bet the favorite to win — find value at 7/2 or higher
  • Rule Win bet must be 7/2+ — if pick moves to favoritism, pivot
  • Rule Trifectas need width — minimum 4-horse box

Bet Structure:

  • 3 bets per race: Win ($50), Exacta Box ($2-$5/unit), Trifecta Box ($1/unit)
  • Total race outlay: ~$86-$104

Signal Scoring System (S1-S10):

  • S1 Elite jockey on bomb (+3)
  • S2 Late tote action (+3) — live odds only
  • S3 Odds drift on quality (+2) — live odds only
  • S4 Trainer win% >15% at meet (+2)
  • S5 Distance stretch-out to sire sweet spot (+2)
  • S6 Best last-race Beyer in field (+1)
  • S7 Blinkers change (+1)
  • S9 Earnings leader in class (+1)
  • S10 First-time starter + expensive pedigree (+1)

Race Analysis Rules (12 principles):

  • Start with the money, respect late action, elite jockey on bombs, odds drift = gift
  • Scratches require rebuild, distance stretch-outs underbet, hot barns at a price
  • Earnings aren't everything in claimers
